🔧 GitHub Setup Required (2 minutes)

Follow these steps to enable comments:

  1. Go to GitHub Personal Access Token
  2. Give it a name: Comments Token
  3. Set expiration: No expiration (or 1 year)
  4. Check the box for: gist scope only
  5. Click "Generate token"
  6. Copy the token (starts with ghp_ or github_pat_)
  7. In this HTML code (line ~165), paste your token
  8. Go to gist.github.com
  9. Create a new public gist:
    • Filename: comments.json
    • Content: [] (just empty brackets)
    • Click "Create public gist"
  10. Copy the Gist ID from the URL (e.g., abc123def456)
  11. Paste the Gist ID in the HTML code (line ~166)
  12. Upload to GitHub Pages!

Once configured, remove this yellow box from the HTML.
